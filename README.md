## Metodología Aplicada

El proyecto se dividió en tres fases críticas para asegurar la integridad de los componentes:

### 1. Diagnóstico de Sistemas

* Inspección física del hardware y periféricos.
* Análisis de errores críticos en el sistema operativo y tiempos de carga.
* Detección de posibles cuellos de botella térmicos.

### 2. Intervención Técnica (Mantenimiento)

* **Limpieza Interna:** Remoción de partículas sólidas en ventiladores y disipadores mediante aire comprimido.
* **Gestión de Conexiones:** Revisión de cables de datos y alimentación para prevenir fallos por falso contacto.
* **Mantenimiento Preventivo:** Optimización de componentes para evitar degradación futura.

### 3. Validación y Control de Calidad

* Ejecución de pruebas de estrés térmico.
* Verificación de integridad de datos y arranque del sistema.
* Certificación de operatividad del equipo.
